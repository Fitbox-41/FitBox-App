# Project Brief: FitBOX Sports

## 1. Overview
FitBOX is a premium mobile fitness application that gamifies the running experience through GPS tracking and territory-capture mechanics. Inspired by the depth and polish of first-party Apple applications (Fitness, Health), FitBOX combines high-performance athletic branding with a quiet, premium aesthetic.

## 2. Brand Identity
- **Name:** FitBOX
- **Logo Style:** Dynamic, forward-leaning italic wordmark with speed lines.
- **Core Palette:** 
  - Primary Surface: Charcoal (#2E2E30)
  - Accent: Signature Red (#E31E24)
  - Secondary Accent: Deep Red (#B3141A) for gradients
- **Visual Style:** Glassmorphism (frosted glass), 1px hairline borders, background blur, and spring-based physics for all motion.

## 3. Core Features & User Journey

### A. Onboarding & Authentication
- **Splash & Onboarding:** Minimalist entry with a focus on core value propositions: tracking, territory capture, and rewards.
- **Secure Access:** Email/Password and Google authentication with a 6-digit OTP verification flow.

### B. Activity Tracking
- **Home Dashboard:** Real-time visibility into daily activity (steps, kcal, distance, minutes) using animated circular progress rings.
- **Live Recording:** GPS-based run tracking with a live map interface, duration, pace, and calorie metrics.
- **Run Summaries:** Post-run details featuring route maps, personal bests, and pace split analysis.

### C. The Game: Territory Capture
- **Territory Map:** A global map where users capture polygons by running within them. Users compete for "Dominator" status in specific sectors (e.g., SoHo, Covent Garden).
- **Leaderboards:** Weekly standings based on territory control and points earned.

### D. Economy & Gamification
- **Wallet & Rewards:** A credit/debit system where activity is converted into points spent in a virtual store.
- **Goals & Achievements:** Customizable daily/weekly targets and a grid of unlockable badges.

## 4. Design Principles (Apple-Grade)
- **Restraint:** Single accent color (Red) against monochrome surfaces.
- **Materiality:** iOS-style translucent materials over deep vertical gradients.
- **Typography:** Large collapsing titles and bold rounded italic numerals for data.
- **Motion:** Staggered fade-ins, spring-based transitions, and shared-element logo animations between screens.

## 5. Technical Requirements
- **Responsive Layout:** Mobile-first design that scales to tablet/desktop via centered max-width containers and side-rail navigation.
- **Theming:** Full support for system-integrated Light and Dark modes.
- **Precision:** Aligned to an 8pt grid with 16-24px safe-zone margins.
